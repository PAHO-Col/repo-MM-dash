== Description ==
Adds a search box to the homepage and lets you search the map by location.
Also uses HTML5's `navigator.geolocation` API to automatically pan the map to the visitor's current location.

== Installation ==
1. Copy the entire directory into your /plugins/ directory.
2. Activate the plugin.
